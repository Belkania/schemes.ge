# Internationalization (i18n) Rules

When modifying or adding pages and components:
1. Always update all 3 dictionaries:
   - `dictionaries/ka.json` (Georgian)
   - `dictionaries/en.json` (English)
   - `dictionaries/ru.json` (Russian)
2. Ensure keys in dictionary files match strictly across all three languages to avoid runtime missing-key issues.
3. For blog posts, check `lib/blogData.tsx` and maintain translations where applicable.
